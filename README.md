# CIO Portfolio — Асет Айтмаганбетов

Готовый статический сайт для https://aitmaganbetov.github.io/.
Не требует сборки, Node.js, базы данных, API-ключей или сторонних CDN.

## Что внутри

- `index.html` — оболочка интерфейса в стиле редактора кода.
- `styles.css` — тёмный дизайн и адаптивная вёрстка.
- `data.js` — профессиональные сведения на RU / KK / EN.
- `app.js` — навигация, локализация, терминал и проверка PDF.
- `assets/portrait.png` — фотография, извлечённая из исходного резюме.
- `assets/resume.pdf` — оригинальный PDF от 30 октября 2026 года.
- `assets/favicon.svg` — значок сайта.
- `.nojekyll` — отключение обработки Jekyll.
- `CONTENT-NOTES.md` — источники и редакционные оговорки для владельца.

Вкладки с расширениями `.tsx`, `.json`, `.md`, `.yml`, `.ts` — элементы интерфейса. Это не отдельные исходные файлы; вся информация находится в `data.js`.

## Предпросмотр

Рекомендуется запускать сайт через локальный HTTP-сервер. Например, при установленном Python откройте терминал в этой папке и выполните:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000/.

При открытии `index.html` двойным щелчком большинство функций работает, но браузер может заблокировать проверку PDF. В этом случае кнопка скачивания скрывается. На GitHub Pages проверка выполняется по HTTPS.

## Публикация через браузер GitHub

Репозиторий: https://github.com/aitmaganbetov/aitmaganbetov.github.io

На момент проверки 30.10.2026 GitHub Pages уже использует `Deploy from a branch`, ветку `main`, папку `/ (root)`.

1. Сохраните резервную копию текущего репозитория: **Code → Download ZIP**.
2. Распакуйте архив этого проекта на компьютере.
3. В репозитории выберите **Add file → Upload files**.
4. Загрузите **содержимое папки `cio-resume`**, включая папку `assets`. Файл `index.html` должен оказаться прямо в корне репозитория, а не внутри дополнительной папки.
5. В форме GitHub проверьте список: заменяется текущий `index.html`, добавляются `styles.css`, `data.js`, `app.js`, `assets/` и документация. Если `.nojekyll` скрыт в проводнике, включите показ скрытых файлов или создайте его через **Add file → Create new file**.
6. Только после проверки нажмите **Commit changes**. Это изменит репозиторий и запустит публикацию.
7. Откройте **Actions**, дождитесь успешного выполнения `pages build and deployment`.
8. Откройте https://aitmaganbetov.github.io/ и обновите страницу с очисткой кеша (`Ctrl+F5`).

Адрес сайта не меняется. Существующие посторонние файлы удалять не требуется. Не загружайте сам ZIP: GitHub Pages не распаковывает архивы.

## Публикация через Git (альтернатива)

В отдельной папке клонируйте существующий репозиторий, скопируйте туда файлы проекта и проверьте изменения:

```sh
git clone https://github.com/aitmaganbetov/aitmaganbetov.github.io.git
cd aitmaganbetov.github.io
# Теперь скопируйте сюда содержимое cio-resume через проводник.
git status
git diff --stat
git diff -- index.html
```

После осознанного подтверждения публикации:

```sh
git add index.html styles.css data.js app.js assets .nojekyll README.md CONTENT-NOTES.md
git commit -m "Add multilingual CIO resume portfolio"
git push origin main
```

Не используйте `--force`. При несовпадении истории сначала разберите изменения в репозитории. Восстановление прежней версии выполняется через `git revert` коммита публикации.

## Редактирование

Изменяйте сведения в `data.js`. Тройные массивы всегда идут в порядке русский, казахский, английский. Тексты интерфейса находятся в объекте `ui` файла `app.js`.

При замене резюме сохраните новый файл как `assets/resume.pdf`, обновите дату и сверяйте сайт с новым источником. Кнопка скачивания появляется только после успешной загрузки файла и проверки сигнатуры `%PDF-`. Если файл удалён, кнопка не отображается.

Команды терминала: `help`, `whoami`, `experience`, `projects`, `skills`, `education`, `contact`, `lang ru`, `lang kk`, `lang en`, `clear`.
Это локальная навигация: команды не исполняются в системе и не отправляются на сервер.
`Ctrl+\`` / `Cmd+\`` переключает терминал; `Escape` закрывает мобильный проводник.
Выбранный язык сохраняется в браузере. Аналитики, трекеров и формы отправки данных нет.

## Проверка после публикации

- Переключите RU / KK / EN и обновите страницу: язык должен сохраниться.
- Откройте все шесть вкладок и разверните обязанности в карьере.
- В карьере должно быть 11 должностей; в образовании — 4 записи; в курсах и сертификатах — 8 записей.
- Проверьте телефон, email, GitHub и скачивание настоящего PDF.
- На телефоне откройте проводник кнопкой меню; вкладки прокручиваются горизонтально.
- Введите `help` и `contact` в терминале.

Подготовка файлов не означает публикацию. Изменения удалённого репозитория в рамках подготовки не выполнялись.
