# CIO Portfolio — Executive × Bento × VS Code Pro

Статический сайт для GitHub Pages. Основной режим — Executive; Developer View открывает проводник, вкладки и локальный терминал. Язык RU/KK/EN и режим сохраняются в браузере. Внешние библиотеки, CDN и трекеры не используются.

## Проверка и сборка

Требуется Node.js 24; устанавливать зависимости не нужно.

```sh
npm run check
npm run build
npx http-server dist -p 4173 -c-1
```

`dist/` содержит готовый сайт. Корень репозитория также полностью совместим с существующим GitHub Pages Deploy from branch. PR workflow только проверяет сборку и ничего не публикует. До слияния PR действующий сайт не меняется.

## Структура

- `data.js`: сведения предоставленного двухстраничного резюме — 11 должностей, 4 записи образования, 8 курсов; обновлены по PDF от владельца.
- `cases.js`: описания пяти авторских проектов; Sapa Monitoring уточнён по актуальному репозиторию krkdev.
- `app.js`: базовая навигация, языки и терминал.
- `executive.js`, `executive.css`: основная главная, Bento-карточки и переключение режима.
- `styles.css`: базовый интерфейс VS Code.
- `index.html`: оболочка, canonical, Open Graph и Person JSON-LD.
- `assets/resume.pdf`: обновлённое трёхстраничное PDF-резюме. Кнопка появляется только после проверки HTTP-ответа и сигнатуры `%PDF-`.
- `robots.txt`, `sitemap.xml`: индексация канонического адреса.

Редактируйте тройные массивы в порядке RU, KK, EN. Подробности источников — в `CONTENT-NOTES.md`.

## Доступность и взаимодействие

Навигация с клавиатуры, видимый фокус, ссылка пропуска навигации, aria-current и aria-pressed, нативные раскрываемые описания, выключение декоративных анимаций через prefers-reduced-motion. Терминал выполняет только команды навигации сайта: help, whoami, experience, projects, skills, education, contact, lang ru|kk|en, clear. Escape закрывает мобильный проводник.

## Ограничения

PDF заново свёрстан на русском с сохранением сведений предоставленного резюме и исправлением проекта Sapa Monitoring; PDF/UA-соответствие не заявляется. Полный внешний аудит WCAG не проводился. Технические названия проектов и декоративные английские метки сохраняются во всех локалях. Клиентская навигация использует hash; языки не являются отдельными индексируемыми URL. Показатели университетских проектов приведены по предоставленному резюме с указанием отчётного периода октября 2026, без заявления о независимом аудите.

## Executive Editorial

Основная версия — светлый редакционный дизайн: крупное имя, serif-типографика, синий акцент, тёмный раздел проектов, результаты и краткая карьера. Слой editorial.js / editorial.css сохраняет тёмный Developer View. Реальная фотография, данные и PDF сохранены без изменений. Схемы возможностей проектов — текстовые представления, не скриншоты продуктов.

Визуальная доработка Editorial: рамка портрета, карточки проектов и переходы к соответствующему раскрытому кейсу, плавное появление блоков через IntersectionObserver. Движение отключается через prefers-reduced-motion; печать и forced-colors сохраняют видимость текста. Внешних зависимостей нет.

## Интегрированная 3D-графика

В первом экране вокруг портрета — прозрачная Canvas-композиция из синих пространственных лент и частиц: перспективная проекция, сортировка по глубине, блики, медленное вращение и реакция на курсор. Светлый фон страницы просвечивает через графику; отдельного чёрного блока и переключателей форм нет. Есть кнопка паузы. В reduced motion композиция статична; вне экрана и в фоне анимация останавливается. При смене раздела очищаются кадры, события и observers. Нет сторонних библиотек, AI-запросов или внешних моделей.
